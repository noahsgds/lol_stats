# Rank Emblems

Place your custom rank emblem images here using these exact filenames:

- `iron.png`
- `bronze.png`
- `silver.png`
- `gold.png`
- `platinum.png`
- `emerald.png`
- `diamond.png`
- `master.png`
- `grandmaster.png`
- `challenger.png`
- `unranked.png` (optional)

These local files take priority over the CDN fallback.
